# Continuité — Guide de prise en main

Application de continuité coiffure et maquillage pour le cinéma. Elle fonctionne **sur votre téléphone, sans compte en ligne** : vos photos et vos fiches restent sur l’appareil.

**Adresse de l’application :** https://mortaada.github.io/continuite-cinema/

---

## 1. Installer l’application

### Android (Chrome)
1. Ouvrez l’adresse ci-dessus dans **Chrome** et attendez quelques secondes.
2. Menu ⋮ → **Installer l’application** (ou **Ajouter à l’écran d’accueil**).
3. Ouvrez Continuité depuis l’icône sur l’écran d’accueil.

### iPhone / iPad (Safari)
1. Ouvrez l’adresse dans **Safari** (pas dans une autre application).
2. Touchez **Partager** (le carré avec une flèche) → **Sur l’écran d’accueil** → **Ajouter**.
3. Ouvrez Continuité **depuis l’icône** de l’écran d’accueil.

> **Important sur iPhone :** installez toujours l’application sur l’écran d’accueil. Dans un simple onglet Safari, iOS peut effacer les données d’un site peu utilisé au bout de quelques jours. L’application installée est protégée contre cet effacement automatique.

Au premier lancement, ouvrez l’application **une fois avec internet** pour qu’elle se prépare. Ensuite elle fonctionne **hors ligne**.

---

## 2. Premier démarrage

1. Saisissez une adresse e-mail (simple étiquette de profil : aucun e-mail n’est envoyé).
2. Choisissez un **code à 6 chiffres** et confirmez-le.
3. L’application affiche un **code de récupération** (ex. `K7QM-2XNP-W4TD-9HRB`). **Notez-le sur papier ou dans un gestionnaire de mots de passe. Il ne sera plus jamais affiché.**

### Si vous oubliez votre code à 6 chiffres
Sur l’écran de verrouillage : **Code oublié ?** → saisissez le code de récupération → choisissez un nouveau code. Un nouveau code de récupération vous est alors remis.

Sans code de récupération et sans sauvegarde, il n’existe **aucun moyen** de récupérer les données : il n’y a pas de serveur ni de compte.

### Sécurité
- Après **5 mauvais codes**, l’application impose une pause (30 s, puis de plus en plus longue).
- L’application se **verrouille automatiquement** si elle reste 2 minutes en arrière-plan.
- Vous pouvez changer votre code et régénérer le code de récupération dans **Plus → Sauvegarde → Sécurité**.

## 3. Utilisation au quotidien

1. **Projets** : créez un film, puis ses personnages, puis ses séquences (une séquence peut concerner plusieurs personnages).
2. **Photographier** : le grand bouton ouvre la caméra sur la dernière séquence utilisée. Chaque photo est enregistrée immédiatement.
3. Touchez la miniature pour ouvrir la photo en plein écran, puis **Détails** pour ajouter coiffure, maquillage, accessoires et notes.
4. **Mes photos** : toutes les photos, avec filtres par film, personnage et séquence.

---

## 4. Sauvegarde — à faire régulièrement

Vos données ne sont **que sur ce téléphone**. Si le téléphone est perdu, cassé, réinitialisé, ou si les données du navigateur sont effacées, tout est perdu **sans sauvegarde**.

1. **Plus → Sauvegarde → Sauvegarder et partager**, puis choisissez **Google Drive** dans la liste (iPhone : « Enregistrer dans Fichiers » → dossier Google Drive). Si Drive n’apparaît pas : **Télécharger la sauvegarde**, puis dans l’application Drive « + » → « Importer ».
2. Envoyez le fichier `.ccbackup` **hors du téléphone** : Google Drive, iCloud, e-mail à vous-même, ordinateur.
3. Faites-le **après chaque journée de tournage**. L’application vous alerte après 7 jours sans sauvegarde.

### Restaurer (nouveau téléphone, ou après un problème)
1. Installez l’application et créez un profil (code + code de récupération).
2. Téléchargez d’abord le fichier `.ccbackup` depuis Drive sur le téléphone, puis **Plus → Sauvegarde → Restaurer un fichier** et choisissez-le.
3. La restauration remplace les données présentes sur l’appareil. Votre code local actuel est conservé : le fichier de sauvegarde ne contient ni code ni code de récupération.

## 5. Problèmes fréquents

| Problème | Que faire |
|---|---|
| Le bouton « Installer » n’apparaît pas (Android) | Utilisez Chrome, attendez quelques secondes, rechargez la page. Si une ancienne version est installée : désinstallez-la, puis Chrome → Paramètres → Paramètres des sites → Toutes les données → supprimer `mortaada.github.io` (⚠ efface les données : faites d’abord une sauvegarde). |
| La caméra ne s’ouvre pas | Autorisez la caméra pour l’application (réglages du téléphone). Sur iPhone : Réglages → Safari (ou l’app installée) → Caméra. |
| « Accès impossible » au lancement | Fermez les autres onglets de l’application, puis touchez **Réessayer**. Évitez la navigation privée. |
| Stockage presque plein | Faites une sauvegarde, puis archivez ou supprimez les photos inutiles. |
| Nouvelle version disponible | Fermez complètement l’application et rouvrez-la avec internet. |

---

## 6. À savoir

- Les photos d’interprètes sont des données personnelles : conservez les sauvegardes dans un endroit sécurisé et supprimez-les quand le projet est terminé.
- Il n’y a pas de synchronisation entre téléphones : chaque appareil a ses propres données. Pour passer d’un appareil à l’autre, utilisez une sauvegarde.
