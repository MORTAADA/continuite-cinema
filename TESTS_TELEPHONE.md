# Liste de contrôle — test sur téléphone réel (≈ 15 min)

À faire sur **Android (Chrome)** puis sur **iPhone (Safari)**, avec l’application installée depuis l’adresse HTTPS publiée. Cochez chaque ligne ; notez le modèle du téléphone et la version du système.

1. [ ] **Installation** : Android « Installer l’application » / iPhone « Sur l’écran d’accueil ». L’icône apparaît, l’application s’ouvre en plein écran.
2. [ ] **Premier lancement** : création du profil (e-mail + code à 6 chiffres), puis formulaire « Commençons » (film, personnage, séquence).
3. [ ] **Caméra** : l’autorisation est demandée ; l’aperçu s’affiche ; le bouton Avant/Arrière change de caméra ; le flash apparaît seulement s’il est géré.
4. [ ] **Prise de vue** : 10 photos d’affilée sans fermer la caméra ; le compteur monte ; aucune photo manquante dans « Mes photos ».
5. [ ] **Qualité** : ouvrir une photo en plein écran et zoomer : la netteté est acceptable pour le travail de continuité (noter la résolution si possible).
6. [ ] **Aperçu plein écran** : Retour à la caméra (la caméra reprend sans redemander l’autorisation), Détails, changement de séquence, Supprimer (confirmation).
7. [ ] **Enregistrement automatique** : saisir une note, fermer l’aperçu immédiatement, rouvrir : la note est là. Fermer puis rouvrir l’application : tout est conservé.
8. [ ] **Hors ligne** : ouvrir l’application une fois avec Internet, passer en mode avion, la rouvrir : elle démarre et les photos sont visibles.
9. [ ] **Sauvegarde** : « Sauvegarder et partager » (ou Télécharger) ; envoyer le fichier vers Drive/e-mail ; vérifier qu’il arrive. Puis **restaurer** ce fichier sur un second appareil ou après avoir vidé l’application de test.
10. [ ] **Volume** : importer ou prendre ≈ 200 photos ; « Mes photos » et l’accueil restent fluides ; le défilement n’est pas saccadé.

Problèmes à signaler : modèle, navigateur, étape, capture d’écran du message d’erreur.
